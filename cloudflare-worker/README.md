# Phoenix Art — безпечний проксі автодоповнення доставки

Сайт на free.1gb.ua залишається статичним. Cloudflare Worker виконує роль невеликого безкоштовного API-проксі, щоб ключі перевізників не потрапляли у відкритий JavaScript сайту.

## 1. Підготувати ключі

- **Нова пошта:** у бізнес-кабінеті Нової пошти відкрийте Налаштування → Безпека → створіть API-ключ. Офіційна інструкція: https://novaposhta.ua/for-business/cooperation/integration/
- **Укрпошта:** адресний класифікатор вимагає Authorization Bearer. За офіційною документацією, його видають після оформлення договору/підключення API. Зверніться до менеджера або api-support@ukrposhta.ua: https://dev.ukrposhta.ua/documentation

## 2. Створити Worker

1. Увійдіть у https://dash.cloudflare.com/ → Workers & Pages → Create → Worker.
2. Створіть Worker `phoenix-art-shipping`.
3. Замініть код Worker кодом із `worker.js` і натисніть Deploy.
4. У Settings → Variables and Secrets додайте:
   - `NP_API_KEY` — API-ключ Нової пошти (**Secret**);
   - `UKRPOSHTA_BEARER` — Bearer Укрпошти (**Secret**);
   - `ALLOWED_ORIGIN` — точний origin вашого сайту, наприклад `https://example.1gb.ua` (без шляху й кінцевого `/`). Якщо сайт доступний через кілька доменів, вкажіть їх через кому. Не ставте `*` для робочого магазину.
5. Перейдіть у Deployments і redeploy Worker після зміни Secrets/Variables, якщо потрібно.

## 3. Під'єднати сайт

У `assets/js/shipping-config.js` установіть `apiBaseUrl` у адресу Worker, наприклад:

```js
window.ART_SHIPPING_CONFIG = {
  apiBaseUrl: 'https://phoenix-art-shipping.YOUR-SUBDOMAIN.workers.dev',
  novaPoshtaApiKey: '',
  parcelLockerTypeRef: ''
};
```

Замість `YOUR-SUBDOMAIN` вставте фактичний піддомен, який видав Cloudflare. Не вставляйте API-ключі у цей файл. Завантажте оновлену папку `assets` на хостинг і зробіть Ctrl+F5.

## 4. Перевірка

- У кошику виберіть «Нова пошта», введіть 2–3 літери міста й оберіть варіант зі списку. Потім оберіть тип пункту та введіть номер/частину адреси.
- Виберіть «Укрпошта», знайдіть населений пункт, а потім поштове відділення за індексом/адресою.
- У DevTools → Network перевірте, що запити до `/api/nova/*` та `/api/ukrposhta/*` повертають `200`.

## Важливі обмеження

- Нова пошта працює після додавання її API-ключа.
- Укрпошта не запрацює, доки не буде отримано офіційний Bearer для адресного класифікатора.
- Worker не зберігає замовлення та персональні дані; він лише проксуює пошукові запити. Не додавайте до запитів ПІБ, телефон або інші дані отримувача.
- Перевірте умови використання API та доступність сервісу для вашого типу облікового запису.
