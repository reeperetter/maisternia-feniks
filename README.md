# Майстерня Фенікс — оновлення головної сторінки

Архів підготовлено для репозиторію `reeperetter/maisternia-feniks`, гілка `main`.

## Що змінює скрипт

- прибирає `position: sticky` у шапки;
- збільшує логотип, назву магазину й навігаційні посилання з адаптацією для мобільних екранів;
- визначає горизонтальні зображення за фактичними розмірами та показує їх без примусового обрізання в картках/промоблоках;
- переносить наявний блок індивідуального замовлення вище блоку «Зараз обирають» і візуально підкреслює його;
- випадково вибирає головне зображення з наявних товарних зображень, використовуючи відповідні файли із суфіксом `-simple`;
- не замінює, не перейменовує та не змінює жодного файла зображення.

## Як застосувати

1. Розпакуйте архів **у корінь локальної копії репозиторію** (там, де лежить `index.html`).
2. Відкрийте термінал у цій папці.
3. Виконайте:

   ```bash
   python3 apply_changes.py
   ```

4. Якщо перевірка базових файлів не пройде, скрипт зупиниться **до внесення змін**. Не обходьте перевірку вручну — спершу порівняйте локальну версію з `main`.
5. Перевірте сайт локально, зокрема ширину 320–390 px і десктопний вигляд.

Скрипт зберігає резервні копії трьох змінених файлів у `.homepage-improvements-backup/`. Він не створює комітів і не змінює GitHub.

## Важливо про стилі

У поточному репозиторії `assets/scss/style.scss` і `assets/css/style.css` уже відрізняються. Щоб не перезаписати або втратити наявні стилі, скрипт не компілює SCSS поверх CSS і не намагається замінити один файл іншим. Він додає однаковий блок нових правил в кінець обох файлів; наявні розбіжності залишаються недоторканими.
