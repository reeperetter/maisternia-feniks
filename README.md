# Майстерня — статичний магазин картин

Багатосторінковий адаптивний шаблон магазину картин за номерами та готових картин. Без Bootstrap, jQuery, серверних скриптів, баз даних або онлайн-оплати.

## Технології
- HTML5 — окремі сторінки;
- SCSS — джерело стилів у `assets/scss/style.scss`;
- CSS — готовий файл `assets/css/style.css`, який підключається на сайті;
- Vanilla JavaScript — каталог, фільтри, пошук, сортування, обране, кошик і форми;
- `localStorage` — збереження кошика й обраного у браузері;
- локальні SVG-зображення для демонстраційного каталогу.

## Сторінки
- `index.html` — головна;
- `catalog.html` — картини за номерами, пошук, фільтри та сортування;
- `ready-art.html` — готові картини;
- `product.html?id=poppy` — картка товару (ID змінюється в URL);
- `cart.html` — кошик та форма замовлення;
- `favorites.html` — обране;
- `custom.html` — індивідуальні замовлення;
- `about.html` — про майстерню;
- `delivery.html` — доставка та оплата;
- `faq.html` — питання та відповіді;
- `contacts.html` — контакти та форма звернення.

## Перед публікацією
1. Відкрийте `assets/js/products.js` і замініть демонстраційні товари, ціни, описи та зображення на власні.
2. У всіх HTML-файлах замініть `YOUR_EMAIL@example.com` у `data-order-email` на адресу, куди мають надходити замовлення. Також замініть адресу на сторінці `contacts.html` і демонстраційні контактні дані.
3. Перевірте реальні умови доставки, оплати, обміну та повернення.
4. Перевірте сайт локально, відкривши `index.html` у браузері.
5. Завантажте вміст папки `art-shop` через файловий менеджер або FTP у кореневу папку сайту на `free.1gb.ua`.

## Як працює оформлення замовлення
- Після налаштування адреси email кнопка сформує лист через `mailto:`. Покупець має поштову програму налаштованою та самостійно натиснути «Надіслати».
- Якщо адреса не налаштована, форма завантажить текстовий файл із замовленням. Це демонстраційний режим, а не доставка замовлення продавцю.
- Сайт не має серверного сховища замовлень, автоматичних сповіщень, обліку залишків або захищеної адміністративної панелі.
- Підписка на розсилку показує демонстраційне повідомлення і не зберігає email.
- Завантаження фото для індивідуального замовлення не реалізовано, оскільки статичний хостинг не має серверного обробника.

## Обмеження хостингу
`free.1gb.ua` призначений для статичних сайтів. Усі інтерактивні функції цього шаблону виконуються в браузері. Для централізованого збереження замовлень, адмінпанелі, авторизації або онлайн-оплати знадобиться інший сервіс чи серверна платформа.


## Додаткові опції

- **Картина за фото замовника:** сторінка `custom.html` містить форму заявки для набору за номерами або готової картини. Фото не завантажується на сервер — клієнт надсилає його окремо після узгодження контакту.
- **Святкове пакування:** доступне в кошику та у формі індивідуального замовлення. Демонстраційна ціна задається змінною `window.ART_GIFT_WRAP_PRICE` на початку `assets/js/products.js` (зараз 100 грн). Перед публікацією замініть її на фактичну ціну; `0` означає безкоштовне пакування.
- **Заявки без серверної частини:** форми відкривають поштовий клієнт через `mailto:` після налаштування `data-order-email` у HTML. Якщо адреса не налаштована, замість надсилання формується текстовий файл для ручного відправлення.
